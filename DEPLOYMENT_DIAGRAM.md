## 문제 해결 플로우차트

```
배포 후 문제 발생?
       │
       ▼
   페이지 깨짐?
    ├─ Yes → CSP 오류 확인 → 도메인 추가
    └─ No
       │
       ▼
   404 오류?
    ├─ Yes → utils.js 경로 확인 → 재배포
    └─ No
       │
       ▼
   기능 안 됨?
    ├─ Yes → Console 오류 확인 → Issue 생성
    └─ No
       │
       ▼
   배포 성공! ✅
```
